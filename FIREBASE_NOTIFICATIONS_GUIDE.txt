Firebase Cloud Messaging (FCM) se hum 4 jagah notifications bhej sakte hain:

  1. ADMIN PANEL    (Next.js web - browser push notification + toast)
  2. TEMPLE PANEL  (Next.js web - browser push notification + toast)
  3. SELLER PANEL  (Next.js web - browser push notification + toast)
  4. APP           (React Native - mobile push notification) [BAAD MEIN]

Hamare paas PostgreSQL hai data ke liye.
Firebase sirf notification delivery ke liye use hoga - database ke liye NAHI.

SECTION 2: HOW FCM WORKS (Simple Explanation)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP A: Browser/App ka Token Register Hona
  - Jab koi admin/temple/seller apne panel me login kare
  - Uska browser Firebase se ek unique "FCM Token" leta hai
  - Ye token hum apne PostgreSQL DB me save karte hain (FCMToken table)
  - Token = us particular browser window ki identity

STEP B: Event Trigger Hona (e.g., new booking)
  - User koi action kare (booking, order, payment)
  - Backend me event fire hota hai

STEP C: Backend Notification Bhejta Hai
  - Backend Firebase Admin SDK se FCM Token pe message bhejta hai
  - Firebase usse us specific browser/device tak deliver karta hai

STEP D: Frontend Notification Show Karta Hai
  - Browser Service Worker notification receive karta hai
  - Toast (Sonner) ya Browser Push notification show hoti hai

  [USER] --> [Backend API] --> [Firebase Admin SDK] --> [FCM] --> [Browser/App]
                  |                                                      |
            [PostgreSQL]                                          [Toast/Push]

SECTION 4: DATABASE DESIGN (FCMToken Table)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Table: FCMToken
  id        - unique ID
  token     - Firebase FCM Token (unique per browser)
  userId    - Kis user ka token hai (User.id / Admin.id / StaffMember.id)
  userType  - 'devotee' | 'admin' | 'temple_admin' | 'seller'
  createdAt - Kab register hua
  updatedAt - Last update

Note: Ek hi user ke multiple tokens ho sakte hain
(different browsers/devices se login kare toh)
